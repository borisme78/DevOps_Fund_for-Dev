# Лабораторна робота: Cisco Packet Tracer (Subnetting, VLAN та конфігурація мережі)

## Огляд
Цей репозиторій містить звіт та опис виконання практичного завдання в симуляторі **Cisco Packet Tracer**, яке включає побудову мережевої топології, проєктування підмереж, налаштування VLAN та конфігурацію кінцевих пристроїв.

---

## Що було зроблено (Хід виконання роботи)

### 1. Встановлення та запуск Cisco Packet Tracer
* Успішно встановлено та запущено середовище моделювання мереж **Cisco Packet Tracer**.

### 2. Побудова топології мережі та налаштування ПК
* Створено мережеву топологію згідно із завданням та наданою схемою.
* **Іменування ПК:** Кінцеві ПК налаштовано з використанням прізвища та номера (наприклад, `melnychuk-PC1`).
* **Конфігурація IP-адрес:** Налаштовано статичні IP-адреси для кожного комп'ютера відповідно до розрахованих підмереж.

### 3. Підмережі (Subnetting)
* Мережу розділено на робочі групи за допомогою підмереж (використано клас C / B IP-адрес).
* Успішно створено щонайменше 3 окремі підмережі для ізоляції та маршрутизації трафіку в топології.

### 4. Налаштування VLAN
* На комутаторах створено 2 окремі віртуальні локальні мережі (**VLAN**).
* Розподілено портфоліо пристроїв та додано відповідні персональні ПК до створених VLAN для забезпечення логічного поділу мережі.
