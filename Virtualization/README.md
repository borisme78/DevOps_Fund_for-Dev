# Лабораторна робота: Віртуалізація (VirtualBox / UTM, Ubuntu Server, Vagrant)

## Огляд
Цей проект демонструє налаштування віртуалізованих середовищ Linux двома основними способами: ручним розгортанням через VirtualBox/UTM з веб-сервером та автоматизованим за допомогою Vagrant.

---

## Що було зроблено (Хід виконання роботи)

### 1. Ручне створення віртуальної машини (VirtualBox / UTM та Ubuntu Server)
* **Встановлення віртуалізації:** Налаштовано та запущено **Oracle VirtualBox** (або альтернативу **UTM** для macOS).
* **Інсталяція ОС:** Завантажено офіційний образ **Ubuntu Server 22.04.5 LTS** (`ubuntu-22.04.5-live-server-amd64.iso`) та виконано установку операційної системи.
* **Перенаправлення портів (Port Forwarding):** 
  У налаштуваннях віртуальної машини налаштовано порти для забезпечення зв'язку з хост-системою:
  * **SSH:** Порт `22`
  * **HTTP:** Порт `80`
* **Налаштування веб-сервера Apache:** 
  Усередині Ubuntu Server встановлено та запущено веб-сервер Apache для перевірки доступності мережі:
  ```bash
  sudo apt update
  sudo apt install apache2 -y
  sudo systemctl start apache2
