# Практичні роботи з баз даних: NoSQL (MongoDB), Міграції (dbmate) та Bytebase


---

## 🛠 Зміст виконаних робіт

### 1. Робота з NoSQL базой даних MongoDB (`mongosh` та GUI)
* **Підключення та налаштування:**
  * Запуск та підключення до сервера MongoDB через інтерактивний shell `mongosh`.
  * Створення та використання бази даних `borys`.
* **CRUD-операції з колекціями:**
  * Створення колекції `books` та додавання документів за допомогою `insertOne()` та `insertMany()` (зберігання інформації про українські літературні твори: назва, автор, кількість сторінок, рік видання, кількість примірників).
  * Пошук та фільтрація даних за допомогою `db.books.find({ year: 1911 })`.
  * Оновлення документів у колекції через оператор `$set` та `updateOne()`.
  * Форматоване виведення списку документів за допомогою `.pretty()`.
* **Використання GUI (MongoDB Compass):**
  * Перегляд бази даних `borys`, її колекцій, документів та індексів через графічний інтерфейс MongoDB Compass.

---

### 2. Управління міграціями реляційних баз даних (`dbmate`)
* **Налаштування та запуск:**
  * Установка й конфігурація інструменту міграції `dbmate` для реляційних баз даних (MariaDB/PostgreSQL).
  * Написання SQL-скриптів міграції для створення та видалення таблиць (наприклад, створення таблиці `users`).
* **Виконання міграцій:**
  * Застосування міграцій до бази даних `staging` за допомогою команди `dbmate up`.
  * Генерація та оновлення підсумкового файлу схеми `db/schema.sql`.
* **Верифікація структури:**
  * Перевірка створених таблиць (`schema_migrations`, `tasks`, `users`) безпосередньо у CLI MariaDB.

---

### 3. Знайомство з платформами управління базами даних (`Bytebase`)
* **Розгортання та запуск:**
  * Ознайомлення з платформами CI/CD та контролю змін для баз даних на прикладі **Bytebase**.
  * Запуск та перевірка логів ініціалізації інстансу PostgreSQL для Bytebase.
