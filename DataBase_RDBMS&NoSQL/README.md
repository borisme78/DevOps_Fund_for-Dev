# Лабораторна робота: MariaDB

1. **Встановлення MariaDB.** Створив віртуальну машину з Ubuntu за допомогою UTM на macOS та встановив у ній MariaDB. Для виконання команд в Ubuntu використовував термінал Tabby, а для роботи з базою через графічний інтерфейс — DBeaver.

2. **Створення бази та підключення.** Створив базу даних `borys`, названу своїм ім’ям. У DBeaver налаштував підключення до MariaDB на віртуальній машині за адресою `192.168.64.3` через порт `3306` і відкрив створену базу.

3. **Створення таблиць.** У базі `borys` створив таблицю `Users` із полями `id`, `FullName`, `Email` та таблицю `Products` із полями `id`, `Name`, `Price`. Для обох таблиць задав автоматичне збільшення первинного ключа `id`, для електронної пошти — унікальність, а для ціни — тип `DECIMAL(10,2)`.

4. **Заповнення та перегляд даних.** Додав двох користувачів — John Doe і Jane Doe, а також два товари — Phone з ціною 15000.00 та Laptop з ціною 40000.00. Переглянув записи в DBeaver і вивів вміст обох таблиць у консолі MariaDB за допомогою запитів `SELECT * FROM Users;` та `SELECT * FROM Products;`.

5. **Створення дампа.** Через термінал Tabby виконав в Ubuntu команду `sudo mariadb-dump borys > borys_dump.sql`, яка зберегла структуру таблиць і дані бази у SQL-файл. Командою `ls` перевірив наявність створеного файлу `borys_dump.sql`.

6. **Відновлення та перевірка.** Створив окрему базу `borys_restored` та імпортував у неї дамп командою `sudo mariadb borys_restored < borys_dump.sql`. Після цього вивів таблиці `Users` і `Products` з оригінальної та відновленої баз. Перевірив, що всі записи збереглися та збігаються в обох базах.
